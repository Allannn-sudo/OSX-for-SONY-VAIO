# Imagining Mac OS X on a VAIO

[简体中文](STORY.zh-CN.md) · [Back to the project](../README.en.md)

## The inspiration

In a 2014 article based on his 2011 interview with former Sony president Kunitake Ando, Nobuyuki Hayashi recounts Ando's memory of Jobs demonstrating a VAIO running Mac OS in Hawaii around 2001. Hayashi labels the Intel OS X interpretation as speculation; his update also cautions about imperfect recollections and dates. [The interviewer's original article](https://nobi.com/en/Steve%20Jobs%20and%20Japan/entry-1212.html)

## What we are building

This project explores that appealing possibility through old hardware we can preserve, study and test today: what would a VAIO running Mac OS X feel like?

The VGN-Y18C is the first documented machine. It has reached the Tiger 10.4.8 desktop while retaining Windows XP, with input, wireless and sleep issues still unresolved. Reproducible steps, failures and recovery procedures belong in the record alongside successful results. Each machine will have its own research record.

This is a personal retrocomputing project inspired by a historical account. The VGN-Y18C, Tiger 10.4.8 and our methods do not represent the original demonstration prototype. The project is not affiliated with Apple, Sony or VAIO.
