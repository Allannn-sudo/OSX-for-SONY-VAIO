# 让 VAIO 运行 Mac OS X 的想象

[English](STORY.en.md) · [返回项目主页](../README.md)

## 灵感来自哪里

林信行（Nobuyuki Hayashi）在 2014 年公开的一篇文章中，转述了他于 2011 年对索尼前社长安藤国威的采访：安藤回忆，约在 2001 年，乔布斯曾在夏威夷展示一台运行 Mac OS 的 VAIO。文章把 Intel 版 OS X 的判断标为推测，后记也提醒，回忆中的日期可能有误。[采访者原文](https://nobi.com/en/Steve%20Jobs%20and%20Japan/entry-1212.html)

## 我们想做什么

这个项目希望用今天能够保存、研究和验证的老硬件，回应那个令人着迷的设想：如果 VAIO 也能运行 Mac OS X，会是什么样子？

VGN-Y18C 是第一台记录在案的实验机器。它已进入 Tiger 10.4.8 桌面，保留了 Windows XP，也留下了仍待解决的输入、无线和睡眠问题。我们把可重复的过程、实际失败和恢复方法一起保存，逐步建立按机型整理的研究档案。

这是一项受历史故事启发的个人复古计算项目。VGN-Y18C、Tiger 10.4.8 和本项目的方法均不代表当年演示原型；项目也不隶属 Apple、Sony 或 VAIO。

## 如何阅读这些记录

- 主页介绍整个 Sony VAIO + Mac OS X 项目与当前路线。
- 机型档案保存各台机器的配置、已确认结果和未解决问题。
- 分支保存某一机型的阶段成果；提交记录和标签帮助追溯变化。

历史叙述以来源和不确定性为边界，机器状态以实测为边界。进入桌面是一项进展，完整支持仍需逐项验证。
