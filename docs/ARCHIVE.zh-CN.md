# 归档范围与使用方式

[English](ARCHIVE.en.md) · [主页](../README.md)

本目录是截至 **2026-10-19** 的公开整理，适合将目录内的内容作为 GitHub 仓库根目录上传。
没有绑定 GitHub 用户名、远程仓库或提交身份，尚未进行推送。

## 保留的内容

- 中英文主页、实机照片及同步的进度与构建说明。
- R3-OFFLINE 研究源码、Apple 版权及 APSL 1.1 全文。
- 可指定外部工具链路径的离线构建脚本、只读加载器格式预检和主机协议模拟。
- 不依赖原版或实验驱动二进制的 41 项便携测试。
- 只读输入状态采集器，以及不含原始日志的状态/历史文件哈希摘要。

`MANIFEST.sha256` 记录本快照其他文件的 SHA256，可用于检查保存或传输后的内容。
它是内容清单，不是数字签名。后续修改文件后需重新生成清单。

## 仅在本地保留的内容

- JaS ISO、制作好的 USB 镜像、Apple 内核/系统文件和驱动二进制。
- Tiger SDK、历史编译器与其他下载文件。
- 原始诊断、系统日志、IORegistry 全量报告、机器或卷标识、个人备份。
- 已撤回的 R2 安装包及危险的旧安装/回退入口。
- 历史界面美化文件和二进制 NIB 补丁。

因此，这个目录不等于整个工作目录的灾难恢复备份。若需要恢复实机或重新构建安装介质，
仍应另存本地介质、真实原版驱动和备份；公开目录不提供安装介质下载。

## 工具边界

便携测试、协议模拟及格式预检运行在现代开发机上，均不加载内核驱动。
完整源码构建需要单独提供旧工具链与 SDK；生成结果仍不能部署。

`tools/Tiger-Input-State/Collect-Input-State.command` 只用于已安装的 i386 Tiger 10.4.8 / Darwin 8.8.1。
它不需要管理员密码，读取状态并写桌面报告，不更改驱动、引导或缓存。归档时修正了早先误用的
`ioreg -r`：Tiger 版本只使用支持的 `-c`、`-w`；不加会输出全部设备属性的 `-l`。
新报告仍可能含现有启动日志和设备标识，回传排查即可，不应直接提交到公开仓库。
新版采集器的实机结果尚待返回。

旧的 33 项加载器检查曾使用本地原版/R2/R3 对象；本仓库的 41 项测试使用独立合成数据，
两者不是同一套测试。11 项协议模拟仍不能替代实际键鼠时序、中断、驱动绑定和唤醒验证。

## 维护

更新实际测试结果时同步修改中英文进度，区分“源码检查通过”“模块加载”“设备绑定”与“用户实际可用”。
`.gitignore` 已排除常见生成物、镜像和私人报告，但它不会自动清理曾被提交到 Git 历史的文件。
